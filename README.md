# Mi Semana en Balance

Dashboard interactivo para organizar trabajo, escuela y vida personal, con calendario mensual/semanal, tareas, prioridades, filtros y asistente de voz de ElevenLabs.

## Enlaces

- [Abrir el dashboard en GitHub Pages](https://wendyvmc.github.io/agenda-wendy/)
- [Descargar el paquete ZIP](https://github.com/WendyVMC/agenda-wendy/raw/refs/heads/main/dashboard-agenda-wendy.zip)
- [Descargar el archivo HTML](https://raw.githubusercontent.com/WendyVMC/agenda-wendy/main/agenda-wendy.html)

## Uso

El dashboard funciona directamente en el navegador. Los eventos y tareas se guardan localmente en el dispositivo desde el que se utiliza.
